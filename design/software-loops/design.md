# Software ecosystem loops

Six silent, ten-second illustrations share the approved Home Assistant visual language.

- Canvas: 1200 × 720, light #f7faf7 with a subtle dotted texture.
- Palette: #f7faf7, #ffffff, #18224f, #004966, #526b91, #16b66a, #8fc31f, #eef6e6.
- Typography: Montserrat regular and bold. Interface labels are secondary to hardware and outcomes.
- Depth: actual transparent XIAO photographs, soft blue shadows, restrained raised surfaces.
- Motion: show an action, show its hardware result, hold for reading, return to a matching loop boundary.
- Home Assistant: sensor measurement and a lamp command.
- Zephyr: one workspace builds for three chip families.
- Seeed GFX2: a common graphics interface draws across three display types.
- ESPHome: product firmware connects plant, button and energy gadgets.
- MicroPython: a REPL command changes an external LED on the board's GPIO.
- SenseCraft AI: a deployed model identifies an object in a camera view.

Illustrated interfaces explain capabilities; they are not live application screenshots.
