# Home Playground Board Assets

These transparent WebP images are derived from the supplied XIAO 2D visual
asset collection. Source PNGs remain unchanged. Processing trims transparent
padding and fits each image inside 360 x 460 pixels at its original aspect ratio,
using WebP quality 90 and alpha quality 100. The 22 files total about 725.5 KiB.
