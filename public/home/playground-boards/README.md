# Home Playground Board Assets

These transparent WebP images are derived from the supplied XIAO 2D visual
asset collection. Source PNGs remain unchanged. Processing trims transparent
padding and fits each image inside 360 x 460 pixels at its original aspect ratio,
using WebP quality 90 and alpha quality 100. The eight files total about 266 KiB.

| WebP file | Source PNG |
| --- | --- |
| esp32-s3.webp | XIAO ESP32-S3 Front.png |
| rp2350.webp | XIAO RP2350 Front.png |
| nrf52840.webp | XIAO nRF52840 Fornt.png |
| mg24.webp | XIAO MG24 Front.png |
| samd21.webp | XIAO SAMD21 Front.png |
| esp32-c6.webp | XIAO ESP32-C6 Front.png |
| ra4m1.webp | XIAO RA4M1 Front.png |
| esp32-c3.webp | XIAO ESP32-C3 Front.png |

Names, intrinsic dimensions and display positions are defined in
`src/app/playground-boards.mjs` at the repository root.
